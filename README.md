# Página web estática responsive

Proyecto de **Diseño de Interfaces Web (DIW)**: una página web estática y adaptable a cualquier dispositivo (móvil, tablet y escritorio), construida con HTML5 y CSS3.


## Objetivos

- Maquetar una página web con HTML5 semántico.
- Aplicar estilos con CSS3 (Flexbox y/o Grid).
- Conseguir un diseño **responsive** mediante *media queries*.
- Seguir buenas prácticas de accesibilidad y organización del código.

## Tecnologías

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura y contenido |
| CSS3 | Estilos y diseño responsive |
| Git y GitHub | Control de versiones y publicación |

## Cómo ejecutarlo

No necesita instalación ni servidor.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/NOMBRE_REPO.git
   ```
2. Entra en la carpeta:
   ```bash
   cd NOMBRE_REPO
   ```
3. Abre `index.html` en tu navegador (doble clic o arrastrándolo a la ventana).
